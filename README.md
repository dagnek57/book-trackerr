# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг. Позволяет добавлять книги с оценкой и датой, просматривать список, среднюю оценку, статистику по авторам и удалять записи. Данные хранятся в JSON-файле.

## Как запустить

1. Убедитесь, что установлен Python 3.6+.
2. Скачайте или клонируйте репозиторий.
3. Запустите командой:

```bash
python main.py
